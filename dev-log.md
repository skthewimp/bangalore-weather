## Session — 2026-04-30 — Alternative data source (NOAA GHCN-Hourly)

### Goal

Find a non-Oikolab source for hourly Bangalore weather (temp / rain / wind) that can be refreshed daily without consuming the 1,500-unit/month free quota.

### Source survey

- **Open-Meteo archive**: free, hourly, daily refresh — but it's ERA5 reanalysis, same model output as Oikolab. No advantage as a sanity check.
- **NOAA ISD**: real station obs, but **deprecated by NOAA in 2025**, archive frozen at 2025-08-24. Dead end for ongoing use.
- **NOAA GHCN-Hourly**: ISD's replacement. Aggregates METAR/SYNOP from airport stations. Free, no key, ~5-7 day lag. **Picked.**
- **IMD**: official, but no clean API. `mausam.imd.gov.in` would need fragile scraping.
- **Meteostat**: wraps ISD/DWD/etc — same upstream as NOAA, extra dependency.

### Stations

Two GHCN-H stations cover Bangalore:

| ID | Name | Coverage |
|---|---|---|
| `INM00043296` | Bangalore HAL Airport | 2005-present |
| `INI0000VOBL` | Kempegowda Intl Airport | 2008-present |

Found via `worldmet::import_ghcn_stations()` filtered to Bangalore bbox. The `worldmet` package itself is broken on v1.0.0 (`column 'remarks' doesn't exist` error in both PSV and parquet readers), so all data fetching is direct PSV downloads from `https://www.ncei.noaa.gov/oa/global-historical-climatology-network/hourly/access/by-year/{YEAR}/psv/GHCNh_{STATION}_{YEAR}.psv`.

### What you get

| Variable | GHCN-H status |
|---|---|
| Temperature | 99.9% complete |
| Wind speed/direction | 99% complete |
| Relative humidity | 99% complete |
| **Precipitation** | **100% NA** — METAR doesn't encode mm |
| Sea-level pressure | empty |

So this source is a station-based replacement for **temp + wind only**. Rainfall still needs Oikolab/ERA5 or an IMD scrape — separate problem.

### Folder layout

Kept entirely separate from main pipeline:

```

├── fetch_historical.R     one-time bulk pull, 22 station-years
├── update.R               delta refresh (current + prior year, dedupe)

├── compare_oikolab.png
└── data/bangaloreISD.RData    461,876 hourly rows
```

`update.R` is not wired into `bangalore_weather_update.R` and does not run on the main daily cadence. It's available if/when we want to switch the temp/wind streams away from Oikolab.
